## Sobre o projeto

O EcoMemory é um jogo educativo desenvolvido em Java como parte das Atividades Práticas Supervisionadas (APS3).

O projeto tem como objetivo estimular a conscientização ambiental por meio de uma atividade interativa de classificação de resíduos, aplicando conceitos de programação orientada a objetos.

## Funcionalidades

- Classificação de resíduos por meio de arrastar e soltar.
- Sete categorias: papel, plástico, metal, vidro, orgânico, eletrônicos e óleo.
- Partidas de 60 segundos com pontuação e sequência de acertos.
- Tutorial e dicas educativas sobre coleta seletiva.
- Animações e mensagens de feedback.
- Histórico dos últimos dez jogos, armazenado em arquivo CSV.
- Interface gráfica com menu, tela de jogo e resultados.

## Tecnologias utilizadas

- **Java:** desenvolvimento do jogo e lógica de programação.
- **Java Swing:** construção da interface gráfica.
- **Programação Orientada a Objetos:** organização das classes e funcionalidades.
- **CSV:** armazenamento do histórico de partidas.

## Como executar

Para executar o EcoMemory no Windows:

1. Instale o **Java JDK**.
2. Baixe o projeto em **Code → Download ZIP**.
3. Extraia os arquivos mantendo a estrutura original.
4. Execute o arquivo `rodar.bat`.

O script compila automaticamente os arquivos Java e inicia o jogo.

O projeto foi desenvolvido para fins acadêmicos, integrando programação orientada a objetos, desenvolvimento de interfaces gráficas e educação ambiental.
